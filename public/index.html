Preguntas Frecuentes

Resuelve tus dudas sobre la API

¿Cómo empiezo a usar la API?

Simplemente conecta tu cuenta de Twitch usando el botón de arriba. Una vez autenticado, obtendrás tu API key personal y podrás configurar los comandos desde el dashboard.

¿Es gratis?

Sí, la API es completamente gratuita. Todos los comandos y herramientas están disponibles sin costo alguno.

¿Necesito un bot para usar los comandos?

Sí, necesitas integrar la API con tu bot de Twitch (como Nightbot, StreamElements, o tu propio bot). La documentación incluye guías para las plataformas más populares.

¿Qué comandos están disponibles?

Tenemos comandos de información (followage, clips, shoutout), herramientas de análisis (tendencias, stalker), y minijuegos (bola 8, ruleta). Revisa la sección de arriba para ver todos los detalles.

¿Dónde puedo obtener soporte?

Puedes revisar la documentación completa, unirte a nuestro servidor de Discord, o enviar feedback directamente desde el dashboard. Estamos aquí para ayudarte.

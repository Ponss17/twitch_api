Documentación Twitch API

Bienvenido a la documentación oficial de la API de Twitch de LosPerris. Aquí encontrarás todo lo necesario para integrar comandos automáticos en tu canal de Twitch.

Esta API está diseñada para ser utilizada principalmente con bots de chat como Nightbot, StreamElements, Fossabot y Wizebot.

Autenticación

La mayoría de los endpoints requieren un token de acceso para funcionar. Puedes obtener tu token conectando tu cuenta en el panel principal.

GET /auth/twitch

Este endpoint inicia el flujo de OAuth con Twitch para obtener tus credenciales.

Crear Clip

Genera un clip instantáneo del canal especificado.

GET /api/create-clip?channel={canal}&token={tu_token}

Parámetros

Parámetro Tipo Descripción
channel String El nombre de usuario del canal (login).
token String Tu Access Token de Twitch.

Ejemplo Nightbot

$(urlfetch https://losperris.site/api/twitch/api/create-clip?channel=$(channel)&token=TU_TOKEN)

Followage

Consulta cuánto tiempo lleva un usuario siguiendo a un canal.

GET /api/followage?channel={canal}&user={usuario}&token={tu_token}

Ejemplo Nightbot

$(urlfetch https://losperris.site/api/twitch/api/followage?channel=$(channel)&user=$(touser)&token=TU_TOKEN)

Listar Clips

Obtiene los clips más recientes de un canal.

GET /api/get-clips?channel={canal}&token={tu_token}&limit=10

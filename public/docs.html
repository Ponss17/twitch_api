LosPerris Twitch API Docs

Bienvenido a la guía oficial. Aquí encontrarás todo lo necesario para configurar tus comandos y herramientas automáticas para tu chat de Twitch.

Compatible: Nightbot, StreamElements, Fossabot y Wizebot.

Caché: Respuestas en memoria por 60s para velocidad.

Tu API Key

La mayoría de los endpoints requieren una apiKey para funcionar. Puedes obtener tu Clave Permanente conectando tu cuenta en el panel principal.

GET /auth/twitch

Este endpoint inicia el flujo de OAuth con Twitch para obtener tus credenciales.

Crear Clip

Genera un clip instantáneo del canal especificado.

GET /api/create-clip?channel={canal}&apiKey={tu_api_key}

Parámetros

Dato Tipo Info
channel String El nombre de usuario del canal (login).
apiKey String Tu Clave Permanente (No expira).

Followage

Consulta cuánto tiempo lleva un usuario siguiendo a un canal.

GET /api/followage?channel={canal}&user={usuario}&apiKey={tu_api_key}

Listar Clips

Obtiene los clips más recientes de un canal.

GET /api/get-clips?channel={canal}&apiKey={tu_api_key}&limit=10

Problemas Comunes

Si algo falla, revisa esto:

Código Qué pasa Solución
401 Unauthorized Tu API Key es inválida.
400 Bad Request Faltan parámetros obligatorios (ej: canal, usuario).
404 Not Found El canal o usuario especificado no existe en Twitch.
500 Server Error Error interno. Contacta con el administrador si persiste.

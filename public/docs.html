LosPerris Twitch API Docs

Bienvenido a la guía oficial. Aquí encontrarás todo lo necesario para configurar tus comandos y herramientas automáticas para tu chat de Twitch.

Compatible: Nightbot, StreamElements, Fossabot y Wizebot.

Caché: Respuestas en memoria por 60s para velocidad.

Tu API Key

La mayoría de los endpoints requieren una apiKey para funcionar. Puedes obtener tu Clave Permanente conectando tu cuenta en el panel principal.

GET /api/twitch/auth/twitch

Este endpoint inicia el flujo de OAuth con Twitch para obtener tus credenciales.

¿Por qué verificar? Solo necesitamos permiso para leer datos públicos y crear clips en tu nombre. No tocamos tu clave de transmisión ni datos privados.

Crear Clip

Genera un clip instantáneo del canal especificado.

GET /api/twitch/create-clip?channel={canal}&apiKey={tu_api_key}

Nota: El canal debe estar en vivo para poder generar un clip. Si el stream está offline, recibirás un mensaje de error.

Parámetros

Dato Tipo Info
channel String El nombre de usuario del canal (login).
apiKey String Tu Clave Permanente (No expira).

Bola 8 Mágica (IA)

Responde preguntas de sí/no de forma divertida usando Inteligencia Artificial. Ahora puedes elegir la personalidad de la respuesta.

GET /api/twitch/minigames/magic8?question={pregunta}&mood={tono}&apiKey={clave}

Parámetros

Dato Tipo Info / Valores
question String La duda existencial del usuario.
mood String classic, sarcastic, toxic, helpful (Opcional, default: classic).
apiKey String Tu Clave Permanente del panel.

Ruleta Rusa

Un juego de alto riesgo para tu chat. Los usuarios prueban su suerte con un revólver virtual de 6 recámaras. Si pierden, reciben un Timeout real (si el bot es mod).

GET /api/twitch/minigames/russian?user={usuario}&apiKey={clave}

Cuidado: Este comando puede expulsar temporalmente a tus usuarios. Úsalo bajo tu propio riesgo.

Duelo

Combate narrativo 1 contra 1. Desafía a otro usuario a un duelo épico con desenlaces aleatorios (Western, Anime, Sci-Fi, etc.). ¡Solo uno quedará en pie!

GET /api/twitch/minigames/duel?challenger={retador}&target={oponente}&apiKey={clave}

Parámetros

Dato Info
target El usuario al que quieres desafiar (ej: @Nightbot).
challenger El usuario que inicia el duelo (opcional).

Herramientas del Dashboard

Tu panel incluye herramientas exclusivas para potenciar tu stream:

Ruleta

La herramienta definitiva para sorteos. Configura una lista de opciones o deja que la API cargue a los usuarios activos del chat en tiempo real. Gira la rueda y celebra al ganador con confeti virtual. Ideal para regalar suscripciones o skins.

Stalker

Tu centro de inteligencia. Investiga a cualquier usuario de Twitch al instante: descubre cuándo creó su cuenta, cuánto tiempo lleva siguiéndote, y ve sus últimos mensajes en tu chat. Perfecto para moderadores que necesitan contexto rápido sobre un viewer sospechoso.

Tendencias

¿Qué está spameando tu chat? Esta herramienta analiza los mensajes en vivo y genera un ranking (Top 10) de las palabras o emotes más repetidos. Úsalo para medir el "hype" de un momento o entender el sentimiento general de tu audiencia.

Problemas Comunes

La API utiliza códigos de estado HTTP estándar para indicar el estado de las solicitudes. Si recibes un error, el cuerpo de la respuesta generalmente contendrá más detalles.

Código Qué pasa Solución
401 Unauthorized Tu API Key es inválida.
400 Bad Request Faltan parámetros obligatorios (ej: canal, usuario).
404 Not Found El canal o usuario especificado no existe en Twitch.
500 Server Error Error interno. Contacta con el administrador si persiste.

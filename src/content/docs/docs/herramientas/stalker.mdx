Herramienta del [panel](/dashboard/stalker) para consultar información **pública** de cuentas de Twitch. No es un comando de chat.

<DashboardAuthNotice />

## Acceso

Abre **[Stalker](/dashboard/stalker)** tras iniciar sesión con Twitch.

## Límites

<Aside type="note" title="Rate limit">
  Perfil (`/user-info`): **límite general** de tu rol (30–120 req/min). Listado de chatters (`/chatters`): **endpoint pesado**, **10 req/min** fijos.
</Aside>

## Uso en el panel

<Steps>
1. Inicia sesión en el [Dashboard](/dashboard).
2. Abre la pestaña **Stalker**.
3. Introduce el login de Twitch (sin `@`) o selecciona un usuario del chat en vivo.
4. Revisa fecha de creación, antigüedad y metadatos del perfil.
</Steps>

## Datos disponibles

- Fecha de creación de la cuenta y antigüedad calculada.
- Avatar, display name, followers y metadatos públicos vía Helix.
- Listado de chatters con roles (mods, VIPs, subs) para el canal en vivo.

<Aside type="note" title="Privacidad">
  Solo se consulta información pública de la API de Twitch. No hay acceso a correos, IPs ni datos privados.
</Aside>

<Aside type="tip" title="Chat en vivo">
  Stalker puede conectarse al chat TMI para abrir el perfil de un viewer con un clic. No requiere comando en el bot.
</Aside>

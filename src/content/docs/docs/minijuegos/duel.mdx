Simula un **duelo 1vs1** entre dos viewers. El ganador se elige al **50 %** y la API devuelve un relato corto en texto plano (prefijo `⚔️`) con menciones `@ganador` y `@perdedor`.

<ApiEndpoint path="/minigames/duel" />
<AuthNotice />

## Parámetros

<ApiParamsTable params={[
  { name: 'target', type: 'string', required: true, description: 'Usuario retado (login de Twitch, sin `@`).' },
  { name: 'challenger', type: 'string', required: false, description: 'Usuario que reta. Si falta, el backend usa `KeanuReeves`. Si el bot no sustituye la variable (`$(user)` sin reemplazar), se usa `Anónimo`.' },
  { name: 'apiKey', type: 'string', required: true, description: 'Clave de API de tu cuenta.' },
]} />

## Escenarios narrativos

Cada duelo elige **un tema al azar** y **un mensaje** de ese tema. Los placeholders `{w}` y `{l}` del backend se sustituyen por `@ganador` y `@perdedor` en la respuesta.

<Aside type="note" title="Comportamiento">
  Probabilidad **50/50** entre `challenger` y `target`. La respuesta es **texto plano** (no JSON) y siempre empieza con `⚔️`. Si retas a ti mismo (`challenger` = `target`), el duelo igual se resuelve y el relato menciona al mismo login como ganador y perdedor.
</Aside>

## Integración con bots

Usa `$(user)` / `$(touser)` (o equivalente) para rellenar retador y oponente:

<Tabs>
  <TabItem label="Nightbot">
    ```text
    !addcom !duelo $(urlfetch https://ttv.losperris.dev/api/minigames/duel?challenger=$(user)&target=$(touser)&apiKey=TU_API_KEY)
    ```
  </TabItem>
  <TabItem label="StreamElements">
    ```text
    !command add !duelo ${customapi.https://ttv.losperris.dev/api/minigames/duel?challenger=${user}&target=${1:}&apiKey=TU_API_KEY}
    ```
  </TabItem>
  <TabItem label="Fossabot">
    ```text
    !addcmd !duelo $(customapi https://ttv.losperris.dev/api/minigames/duel?challenger=$(user)&target=$(1)&apiKey=TU_API_KEY)
    ```
  </TabItem>
  <TabItem label="Wizebot">
    ```text
    !command add !duelo $(urlfetch https://ttv.losperris.dev/api/minigames/duel?challenger=$(user_name)&target=$(arg_1)&apiKey=TU_API_KEY)
    ```
  </TabItem>
</Tabs>

El viewer ejecuta `!duelo @usuario` en el chat; el bot llama a la API y devuelve el relato del duelo.

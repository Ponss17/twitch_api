Responde preguntas del chat con inteligencia artificial. A diferencia de respuestas fijas, el modelo interpreta el contexto de cada pregunta y adapta el tono según la personalidad elegida.

<ApiEndpoint path="/minigames/magic8" />

## Parámetros

<ApiParamsTable params={[
  { name: 'question', type: 'string', required: true, description: 'Pregunta del viewer (3–500 caracteres).' },
  { name: 'apiKey', type: 'string', required: true, description: 'Clave de API de tu cuenta.' },
  { name: 'user', type: 'string', required: false, description: 'Usuario que pregunta; la IA se dirige a `@user` en la respuesta.' },
  { name: 'mood', type: 'string', required: false, description: 'Personalidad de la respuesta. Por defecto `classic`. Ver opciones abajo.' },
]} />

## Personalidades (`mood`)

El parámetro opcional `mood` define cómo habla la bola. **Por defecto:** `classic`. Si envías un valor no reconocido, se usa `classic` (mismas opciones que el selector **Personalidad** del panel).

<Aside type="caution" title="Modo tóxico">
  `toxic` puede sonar agresivo o incómodo en chat público. Prueba la personalidad en el panel antes de activarla en el bot.
</Aside>

Añade `&mood=` a la URL del comando:

```text
https://ttv.losperris.dev/api/minigames/magic8?question=$(querystring)&mood=sarcastic&user=$(user)&apiKey=TU_API_KEY
```

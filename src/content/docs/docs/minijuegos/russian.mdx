El viewer aprieta el gatillo: hay 6 recámaras y una bala. Si pierde, puede recibir timeout automático (modo hardcore).

<ApiEndpoint path="/minigames/russian" />
<AuthNotice />

<Aside type="danger" title="Permisos de moderador">
  El bot debe ser **moderador** del canal para aplicar timeouts. Sin permisos, el timeout no se ejecutará.
</Aside>

## Parámetros

<ApiParamsTable params={[
  { name: 'channel', type: 'string', required: true, description: 'Canal donde se ejecuta el juego.' },

  { name: 'apiKey', type: 'string', required: true, description: 'Clave de API de tu cuenta.' },

## Comportamiento

1. El viewer ejecuta el comando en el chat.
2. La API simula la ruleta rusa.
3. Si pierde y `hardcore=true`, el bot aplica timeout vía permisos de moderador.

Devuelve clips recientes de un canal en **JSON**. Sirve para widgets, carruseles en OBS o integraciones web — no es un comando de chat. Para crear clips desde el bot, usa **[Crear clip](/docs/comandos/clips/)**.

<ApiEndpoint path="/dashboard/get-clips" />
<AuthNotice />

## Límites

<Aside type="note" title="Endpoint pesado">
  Usa el **límite pesado** de tu rol (Default **5** → Partner **40** req/min), independiente del límite general. Las respuestas se cachean según tu rol (ver [Límites](/docs/limits/)).
</Aside>

## Parámetros

<ApiParamsTable params={[
  { name: 'channel', type: 'string', required: true, description: 'Login del canal de Twitch (sin `@`).' },
  { name: 'apiKey', type: 'string', required: true, description: 'Clave de API de tu cuenta.' },
  { name: 'limit', type: 'number', required: false, description: 'Cantidad de clips (1–100). Por defecto **20**.' },
]} />

<div class="api-flow">

## Ejemplo de petición

<ApiFlowRequest
  flowId="flow-get-clips"
  path="/dashboard/get-clips"
  accept="application/json"
  query={{
    channel: 'ElGamerX',
    limit: '5',
    apiKey: 'TU_API_KEY',
  }}
/>

Campos principales de cada clip: `id`, `url`, `embed_url`, `broadcaster_name`, `creator_name`, `title`, `view_count`, `created_at`, `thumbnail_url`, `duration`.

<Aside type="tip" title="CORS">
  Las peticiones GET incluyen cabeceras CORS abiertas. Puedes consumir el endpoint con `fetch()` desde el frontend.
</Aside>

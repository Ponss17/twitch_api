El dashboard está en [ttv.losperris.dev/dashboard](https://ttv.losperris.dev/dashboard). Desde ahí gestionas comandos de chat, herramientas con overlay OBS, analytics y tu API Key.

<Aside type="note" title="Configuración">
  **Configuración** (API Key, zona horaria, exportar datos, zona de peligro) no está en la barra lateral: ábrela desde el **menú de tu cuenta** arriba a la derecha → **Configuración** ([`/dashboard/settings`](/dashboard/settings)).
</Aside>

## Sesión y datos en vivo

Tras el login con Twitch, el panel canjea un token de un solo uso y valida la sesión antes de cargar datos:

1. **OAuth** → redirect a `/dashboard/?auth=…`
2. **`GET /api/auth/exchange`** → devuelve `apiKey`, perfil y token de Twitch
3. **`GET /api/system/validate`** → confirma sesión y refresca token si hace falta

<Aside type="note" title="Pestaña líder">
  Con varias pestañas del panel abiertas, solo la **líder** mantiene Realtime activo (Supabase). Las demás sincronizan por `BroadcastChannel`. Si Realtime falla, hay polling de respaldo.
</Aside>

<Aside type="caution" title="Rate limit del panel">
  Las peticiones con sesión OAuth usan un límite de sesión que escala con tu rol (mínimo **500 req/min**), distinto del límite de API Key para bots. Ver [Límites](/docs/limits/).
</Aside>

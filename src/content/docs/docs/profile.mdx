La página **Configuración** concentra todo lo relacionado con tu cuenta. Está organizada en **tres pestañas** (estilo Nightbot): General, Seguridad y Conexiones.

URL base: [ttv.losperris.dev/dashboard/settings](https://ttv.losperris.dev/dashboard/settings)

<Aside type="note" title="Cómo abrirla">
  No está en la barra lateral del panel. Usa el **menú de tu cuenta** (arriba a la derecha, avatar o nombre) → **Configuración**.
</Aside>

---

## Acceso rápido

<Steps>
1. [Inicia sesión](/docs/inicio-rapido/) con Twitch.
2. Abre el menú de cuenta → **Configuración**.
3. Elige la pestaña que necesites (General, Seguridad o Conexiones).
</Steps>

La vista carga tu perfil desde `/api/dashboard/summary` y lo actualiza en segundo plano mientras la pestaña de Configuración está visible.

---

## Pestañas y URLs

Cada pestaña tiene su propia ruta. Puedes copiar el enlace o usar atrás/adelante del navegador.

| Pestaña | URL | Contenido |
| :--- | :--- | :--- |
| **General** | [`/dashboard/settings`](/dashboard/settings) | User ID, plan/cuota, zona horaria, exportar datos |
| **Seguridad** | [`/dashboard/settings/seguridad`](/dashboard/settings/seguridad) | API Key + zona de peligro |
| **Conexiones** | [`/dashboard/settings/conexiones`](/dashboard/settings/conexiones) | Vincular / desvincular Discord |

<Aside type="tip" title="Atajos">
  Tras vincular Discord con OAuth, el panel te lleva solo a **Conexiones**. La última pestaña visitada se recuerda al volver a Configuración.
</Aside>

## General

### Cuenta

| Dato | Qué es |
| :--- | :--- |
| **User ID** | Tu ID numérico de Twitch; pulsa para copiarlo. |
| **Plan y cuota** | Rol (Default, Pro, VIP, Partner), `req/min`, `heavy/min` y TTL de caché. Un `*` indica override personalizado. |

Estos chips también definen tus [límites de uso](/docs/limits/).

### Preferencias

Zona horaria **IANA** (con búsqueda). Afecta cómo se agrupan **días y horas** en estadísticas y en el reporte HTML.

Al primer login, el OAuth también envía la zona del navegador (`tz` en `/api/auth/twitch`).

<Steps>
1. Elige la zona en el desplegable (p. ej. `Europe/Madrid` o `America/Mexico_City`).
2. Pulsa **Guardar** (solo activo si cambiaste el valor).
</Steps>

<ApiEndpoint method="PATCH" path="/dashboard/settings" />

<ApiParamsTable params={[
  { name: 'timezone', type: 'string', required: true, description: 'Identificador IANA (p. ej. America/Mexico_City, UTC).' },
]} />

Cuerpo JSON: `{ "timezone": "Europe/Madrid" }`

### Datos (exportar)

Genera un **reporte de cuenta completo** en HTML o un **CSV de analíticas** (resumen, uso por comando y serie de 7 días). El CSV se arma en el navegador con los mismos datos; no añade endpoints nuevos.

Nombre al descargar:

```text
MisDatos_LosPerrisAPI_tu_login.html
Analytics_LosPerrisAPI_tu_login.csv
```

| Bloque del reporte | Detalle |
| :--- | :--- |
| Perfil | Avatar, login y tipo de canal de Twitch. |
| Métricas | Peticiones hoy y totales, latencia media, tasa de éxito. |
| Por categoría | Totales de comandos, herramientas y minijuegos. |
| Integraciones | Ejemplos de sintaxis para tu bot con la API Key ya insertada (Followage, Clips, Shoutout…). |

<Aside type="caution" title="Contenido sensible">
  El reporte puede incluir tu **API Key** y datos de uso. Guárdalo en un lugar seguro; no lo subas a repos públicos ni lo compartas en stream.
</Aside>

Entre descargas hay **4 minutos** de espera por usuario. Si intentas antes, verás cuánto falta (`429` en `export-check`).

<Steps>
1. Pulsa **Generar reporte**.
2. El panel verifica el cooldown (`POST /api/dashboard/export-check`).
3. Se arma el HTML o el CSV en el navegador y se descarga solo.
4. Se registra la exportación (`POST /api/dashboard/export-complete`).
</Steps>

| Paso API | Método | Ruta |
| :--- | :--- | :--- |
| Verificar cooldown | `POST` | `/api/dashboard/export-check` |
| Registrar exportación | `POST` | `/api/dashboard/export-complete` |

## Seguridad

### API Key

Gestiona la credencial de tus bots.

| Acción | Comportamiento |
| :--- | :--- |
| **Ver / ocultar** | Muestra el UUID completo; se **oculta sola a los 30 s**. |
| **Copiar** | Copia la clave al portapapeles (también arranca el temporizador de 30 s). |
| **Regenerar** | Abre un modal de confirmación; la clave anterior deja de funcionar al instante. |
| **⚠ (triángulo)** | Hace scroll hasta la **zona de peligro** (siempre visible en esta pestaña). |

Por defecto la clave aparece **enmascarada**. No la compartas en directo ni en capturas.

Debajo del campo verás el chip **Activa** cuando la clave está operativa.

<Aside type="danger" title="Regenerar clave">
  Tras regenerar, actualiza **todas** las URLs en Nightbot, StreamElements, Fossabot y Wizebot. Ver [Tu API Key](/docs/auth/).
</Aside>

<ApiEndpoint method="POST" path="/system/regenerate-key" />

Requiere sesión OAuth del panel y protección CSRF.

### Zona de peligro

Siempre visible en la pestaña **Seguridad**. Cada acción abre un modal: debes escribir la palabra exacta.

| Acción | Palabra | Qué borra | Qué se mantiene |
| :--- | :--- | :--- | :--- |
| **Reiniciar estadísticas** | `LIMPIAR` | Historial de comandos, clips, latencia, gráficas y feed de actividad. | Cuenta, OAuth y **API Key activa**. |
| **Eliminar cuenta** | `ELIMINAR` | Perfil en LosPerris, datos asociados y API Key. | Tu **cuenta de Twitch** no se toca. |

<Aside type="danger" title="Eliminar cuenta">
  Irreversible en LosPerris API. Tras confirmar, redirige a la landing en unos segundos. Exporta el reporte antes si necesitas un histórico.
</Aside>

<ApiEndpoint method="POST" path="/dashboard/clear-data" />

Cuerpo: `{ "confirm": "LIMPIAR" }`

<ApiEndpoint method="DELETE" path="/dashboard/delete-account" />

Cuerpo: `{ "confirm": "ELIMINAR" }`

Ambos requieren sesión del panel y CSRF.

## Conexiones

Vincula tu cuenta de **Discord** a LosPerris (avisos de sesión, feedback como Discord, etc.).

| Estado | Qué puedes hacer |
| :--- | :--- |
| Sin vincular | **Vincular Discord** → OAuth de Discord → vuelves a Configuración → Conexiones |
| Vinculado | Ves usuario/avatar y puedes **Desvincular** (con confirmación) |

Si el enlace de Discord ya está usado por otra cuenta Twitch, verás un error y no se completa el vínculo.

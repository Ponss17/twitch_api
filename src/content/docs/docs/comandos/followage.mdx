Consulta la antigüedad del follow de un viewer. La respuesta es texto plano listo para mostrar en el chat.

<ApiEndpoint path="/followage" />
<AuthNotice />

## Límites

<Aside type="note" title="Rate limit">
  Usa el **límite general** de tu rol (30–120 req/min). En cuentas Default, las respuestas se cachean **60 segundos** para reducir peticiones repetidas en el chat.
</Aside>

## Parámetros

<ApiParamsTable params={[
  { name: 'channel', type: 'string', required: true, description: 'Canal de Twitch donde se ejecuta el comando.' },
  { name: 'user', type: 'string', required: true, description: 'Usuario cuya antigüedad de follow se consulta.' },
  { name: 'apiKey', type: 'string', required: true, description: 'Clave de API de tu cuenta.' },
  { name: 'template', type: 'string', required: false, description: 'Plantilla personalizada con `{user}`, `{time}` y `{channel}`.' },
]} />

<div class="api-flow">

## Ejemplo de petición

Con **cURL** o **URL** la respuesta muestra solo el mensaje. Con **cURL -i** ves cabeceras HTTP + cuerpo.

<ApiFlowRequest
  flowId="flow-followage"
  path="/followage"
  query={{
    channel: 'losperris',
    user: 'viewer123',
    apiKey: 'TU_API_KEY',
  }}
/>

## Plantillas personalizadas

Añade `template` para controlar el mensaje del bot. Placeholders: `{user}`, `{time}` y `{channel}`.

<ApiRequestExample
  path="/followage"
  query={{
    channel: 'losperris',
    user: 'viewer123',
    apiKey: 'TU_API_KEY',
    template: '{user} lleva {time} siguiendo a {channel}',
  }}
/>

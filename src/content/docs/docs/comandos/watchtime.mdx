Consulta el tiempo de permanencia o seguimiento de un viewer en tu canal con un mensaje enfocado en el tiempo que lleva viéndote. La respuesta es texto plano lista para bots como Nightbot, StreamElements, etc.

<ApiEndpoint path="/watchtime" />
<AuthNotice />

## Límites

<Aside type="note" title="Rate limit y caché">
  Usa el **límite general** de tu rol (30–120 req/min). Las respuestas se cachean según el rol (Default **60 s** → Partner **240 s**).
  Se guarda la **fecha inicial**; en cada acierto de caché el tiempo se **recalcula en tiempo real**, sin llamar otra vez a Twitch.
</Aside>

## Ejemplo de petición

Con **cURL** o **URL** la respuesta muestra solo el mensaje. Con **cURL -i** ves cabeceras HTTP + cuerpo.

<ApiFlowRequest
  flowId="flow-watchtime"
  path="/watchtime"
  query={{
    channel: 'losperris',
    user: 'viewer123',
    apiKey: 'TU_API_KEY',
  }}
/>

## Plantillas personalizadas

Añade `template` para controlar el mensaje del bot. Placeholders: `{user}`, `{time}` y `{channel}`.

<ApiRequestExample
  path="/watchtime"
  query={{
    channel: 'losperris',
    user: 'viewer123',
    apiKey: 'TU_API_KEY',
    template: '{user} lleva {time} viendo a {channel}',
  }}
/>

Genera un mensaje de promoción con la categoría reciente y el enlace del canal objetivo. Consulta la API de Twitch en cada petición (sin caché KV como followage).

<ApiEndpoint path="/shoutout" />
<AuthNotice />

## Límites

<Aside type="note" title="Rate limit">
  Usa el **límite general** de tu rol (30–120 req/min). En respuestas exitosas, el CDN puede cachear el texto **10 segundos** (`Cache-Control: s-maxage=10`).
</Aside>

## Parámetros

<ApiParamsTable params={[
  { name: 'channel', type: 'string', required: true, description: 'Canal donde se ejecuta el comando.' },
  { name: 'touser', type: 'string', required: true, description: 'Streamer a promocionar.' },
  { name: 'apiKey', type: 'string', required: true, description: 'Clave de API de tu cuenta.' },
  { name: 'template', type: 'string', required: false, description: 'Plantilla con `{user}`, `{game}` y `{url}`.' },
]} />

<div class="api-flow">

## Ejemplo de petición

<ApiFlowRequest
  flowId="flow-shoutout"
  path="/shoutout"
  query={{
    channel: 'losperris',
    touser: 'ninja',
    apiKey: 'TU_API_KEY',
  }}
/>

## Plantillas personalizadas

Añade `template` para controlar el mensaje. Placeholders: `{user}`, `{game}` y `{url}`.

<ApiRequestExample
  path="/shoutout"
  query={{
    channel: 'losperris',
    touser: 'ninja',
    apiKey: 'TU_API_KEY',
    template: 'Sigue a {user}, jugaba {game}: {url}',
  }}
/>

Crea un clip del stream en vivo desde el chat.

<ApiEndpoint path="/create-clip" />
<AuthNotice />

## Requisitos

1. El canal debe estar **en vivo**.
2. La creación de clips debe estar **habilitada** en el panel de Twitch.

## Límites

<Aside type="note" title="Rate limit">
  Usa el **límite general** de tu rol (30–120 req/min). Configura un cooldown de 30–60 s en el bot para no spamear la API de Twitch.
</Aside>

## Ejemplo de petición

<ApiFlowRequest
  flowId="flow-create-clip"
  path="/create-clip"
  query={{
    channel: 'losperris',
    apiKey: 'TU_API_KEY',
    user: 'viewer123',
  }}
/>

## Plantillas personalizadas

Añade `template` para personalizar el mensaje del bot. Placeholders: `{user}`, `{url}`, `{title}` y `{channel}`.

<ApiRequestExample
  path="/create-clip"
  query={{
    channel: 'losperris',
    apiKey: 'TU_API_KEY',
    user: 'viewer123',
    template: 'Clip de {user}: {url}',
  }}
/>

## Integración con bots

<Aside type="note" title="Wizebot y Fossabot">
  Wizebot y Fossabot ya incluyen el comando nativo `!clip` para crear clips del directo. No necesitas integrar este endpoint si usas alguno de esos bots.
</Aside>

<Tabs>
  <TabItem label="Nightbot">
    ```text
    !addcom !clip $(urlfetch https://ttv.losperris.dev/api/create-clip?channel=$(channel)&apiKey=TU_API_KEY)
    ```
  </TabItem>
  <TabItem label="StreamElements">
    ```text
    !command add !clip ${customapi.https://ttv.losperris.dev/api/create-clip?channel=${channel}&apiKey=TU_API_KEY}

    ```
  </TabItem>
